01 Integration engine

CarrierBridge

Pulls insurance policies from carriers that each work differently, and returns one clean, versioned format.

Open source Runs locally with Docker Compose

Every carrier integrates differently. One is a modern OAuth REST API. One is a legacy service that reports errors as HTTP 200 and sends premiums as "$1,284.6". One has no API at all, so CarrierBridge logs in with a headless browser. All three sit behind a single adapter interface and come out as the same NormalizedPolicy contract. The carriers are realistic mock services with scripted faults, so every failure path is tested.

  • Async pulls on a Postgres queue

    POST /pulls returns 202 right away. Workers claim one task per carrier with SKIP LOCKED, leases, and fencing tokens, so a stalled worker can never overwrite a newer attempt.

  • Partial success, not all-or-nothing

    Every failure is classified (authentication, rate limited, carrier unavailable, timeout) to decide whether to retry. One carrier failing never throws away another carrier's results.

  • Normalization that never invents data

    Integer cents, calendar dates, VIN check digits, and explicit enum tables. Anything unparseable becomes null with a warning, and the raw value is kept.

  • Credentials handled like secrets

    AES-256-GCM encrypted while queued, bound to their task, deleted once the task finishes, and tested to never appear in responses or logs.

02 TyKu Technologies

BindHQ

An agency management system and CRM for independent insurance agencies.

V1 live in production V2 in progress

Independent agencies run on legacy software that's expensive, slow, and dated. BindHQ covers the 80–90% of features agencies use every day, with the speed and polish of tools like Linear or Stripe. It's a true multi-tenant SaaS, and its first real tenant is TyKu's own insurance agency.

  • Tenant isolation in the database

    Every agency is walled off by forced Postgres row-level security and composite foreign keys. Even a missing WHERE clause can't leak another agency's client data.

  • Policy history as a ledger

    Each renewal inserts a new policy term instead of overwriting the last one, so past premiums are never lost.

  • Audited before release

    V1 passed a 16-point acceptance audit run against production, with zero cross-tenant data exposure.

  • Built for the real workflow

    Households, contacts, producer/CSR assignment, carriers, lines of business, policies, notes, activity timeline, team invites, and role-based access.

03 Black Box Media

Black Box Fragrances

A personal fragrance decision engine, built for an audience of 70,000+.

Live in production Co-founder · product & engineering

Black Box is a fragrance channel on TikTok and YouTube with 100K+ weekly views. The platform turns viewers into users: a three-minute taste quiz builds a Scent Profile, then every fragrance gets an explainable Match Score and a Bottle Check verdict (buy, sample first, consider, or skip) that also knows what's already in your collection.

  • Explainable, not "AI"

    Scoring is deterministic and fully tested. Every score shows its reasons and a separate confidence level, and it's checked against a hand-curated set of taste personas.

  • Knows your collection

    Bottle Check warns when a new bottle duplicates one you already own. Collection Intelligence tells you what your shelf says about your taste.

  • Built to grow

    Daily Head-to-Head voting, public profiles, campaign links from videos, and per-product affiliate links through FragranceNet and DecantX.

  • Private by default

    Passwordless email sign-in, server-side authorization that fails closed, and automated tests proving one user can never read another's data.
